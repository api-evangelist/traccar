Traccar provides a free and open source GPS tracking platform that enables users to monitor and manage devices in real time. The system supports self‑hosting on Windows, Linux, or cloud environments, as well as managed hosting services. It offers a web interface, mobile apps, and extensive device compatibility, allowing businesses and individuals to track assets, receive alerts, generate reports, and integrate with other systems via APIs.

**Areas:** GPS Tracking · Open Source Software · Managed Hosting

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Traccar: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
